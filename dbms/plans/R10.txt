Query ID: R10
Type: READ
Description: Tenant complaints: complaints raised by the logged-in tenant
Query SQL:
SELECT c.id,
       c.category,
       c.title,
       c.description,
       c.priority,
       c.status,
       c.assigned_to,
       c.resolution_notes,
       c.created_at,
       c.updated_at,
       p.name AS property_name
FROM   complaints c
JOIN   properties p ON p.id = c.property_id
WHERE  c.tenant_id = 'tenant-uuid-here'
ORDER  BY c.created_at DESC;
