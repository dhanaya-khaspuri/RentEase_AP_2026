Query ID: R11
Type: READ
Description: Notices: all pinned-first notices for a property
Query SQL:
SELECT n.id,
       n.title,
       n.category,
       n.content,
       n.author,
       n.priority,
       n.is_pinned,
       n.created_at
FROM   notices n
WHERE  n.property_id = 'property-uuid-here'
ORDER  BY n.is_pinned DESC, n.created_at DESC;
