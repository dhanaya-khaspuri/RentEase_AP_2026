Query ID: R4
Type: READ
Description: Room list: all rooms for a given property with occupancy status
Query SQL:
SELECT r.id,
       r.room_number,
       r.floor,
       r.capacity,
       r.occupied,
       r.rent,
       r.type,
       r.has_ac,
       r.has_attached_bath,
       (r.capacity - r.occupied) AS available_beds
FROM   rooms r
WHERE  r.property_id = 'property-uuid-here'
ORDER  BY r.floor, r.room_number;
